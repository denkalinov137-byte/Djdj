# DERMUX RU — круговой Android-пульт команд

**Бренд:** DERMUX RU · **Авторская подпись:** by @osaoda  
**Назначение:** один настоящий Android home-screen widget, который открывает русское круговое меню, похожее на radial selector из CS. Виджет не заменяет Termux:Widget — это отдельный Android AppWidget внутри собственного приложения.

## Важно понимать

- В архиве лежат исходники Android-приложения и Termux-интеграция. Готовый APK здесь не приложен: в окружении создания архива нет Android SDK/Gradle, а сеть контейнера отключена, поэтому APK нельзя было честно собрать и проверить.
- Android намеренно не позволяет приложению молча положить виджет на главный экран. При первом запуске DERMUX делает запрос на закрепление; нужно подтвердить его в интерфейсе лаунчера. Если запрос не поддерживается, добавь DERMUX через **Главный экран → Виджеты**.
- Приложение вызывает команды через официальную схему Termux `RUN_COMMAND`. Для этого нужны Termux, установка скрипта `dispatch.sh`, настройка `allow-external-apps=true` с согласием владельца и Android-разрешение на запуск команд. Без этих шагов меню откроется, но команды не запустятся.
- Termux и дополнения должны быть подписаны совместимым источником. Не устанавливай APK из случайных сайтов.

## Что есть

- Один нативный виджет `DERMUX — КОЛЕСО КОМАНД` (переразмериваемый, если это позволяет лаунчер).
- Круговой селектор на 8 секторов; тап по сектору открывает категорию, тап по центру возвращает назад, кнопки листают команды внутри категории.
- 8 категорий и 72 команды/действия в каталоге: система, сеть, OSINT, WEB, разработка, файлы, инструменты и настройки.
- Русские названия и подсказки, диалоги ввода домена/IP/текста/пути, валидация введённых значений.
- Пассивные источники OSINT: DNS, WHOIS, RDAP, Certificate Transparency, SPF/DMARC, security.txt, sitemap, заголовки HTTPS, TLS, robots.txt, открытый title страницы, цепочки редиректов, хэш публичного favicon. Запросы к внешним сервисам показывают подтверждение внутри Termux.
- Без root. LAN discovery ограничен частными IPv4-подсетями /24–/32 и спрашивает подтверждение.
- Отдельный bridge со строгим `case`-списком команд. Введённое значение передаётся одним аргументом, не запускается через `eval`.

## Шаг 1 — установить Termux-часть

1. Распакуй архив так, чтобы папка `DERMUX_RU_WHEEL/termux/` оказалась доступна Termux. Проще всего положить ZIP в Download, открыть Termux и выполнить:

```bash
termux-setup-storage
pkg install unzip -y
cd ~/storage/downloads
unzip -o DERMUX_RU_WHEEL.zip
cd DERMUX_RU_WHEEL/termux
bash install-termux.sh
```

2. Установщик отдельно спросит согласие на изменения пакетов и на включение `allow-external-apps=true`. Сначала просмотри источники APT, если в твоём Termux есть неизвестные репозитории. Не подтверждай пакеты из неизвестного источника.
3. После установки проверь локальную часть:

```bash
bash ~/.dermux/android/dispatch.sh selfcheck
bash ~/.dermux/android/dispatch.sh dashboard
```

Если `termux-setup-storage` спрашивает, перестроить ли существующие ссылки `~/storage`, отвечай `n`, если не понимаешь, зачем нужно перестроение. Содержимое общей памяти при этой операции не удаляется, но сами ссылки будут обновлены.

## Шаг 2 — собрать Android-приложение

### Android Studio

1. Открой папку `android/` в Android Studio.
2. Используй JDK 17, Gradle 8.13 и Android SDK Platform 35.
3. Нажми **Build → Build APK(s)**.
4. Файл появится в `android/app/build/outputs/apk/debug/app-debug.apk`.
5. Установи APK на телефон и открой **DERMUX RU**.

### Автосборка через GitHub Actions

В архив включён `.github/workflows/build-debug-apk.yml`. Если проект размещён в своём репозитории GitHub с сохранением структуры каталогов, открой **Actions → Собрать DERMUX RU APK → Run workflow**. После успешного запуска скачай `DERMUX-RU-debug-apk` из Artifacts. APK debug подписан тестовым ключом и подходит для локальной установки, а не для публикации в магазине.

## Шаг 3 — разрешить запуск команд

1. Открой **Настройки Android → Приложения → DERMUX RU → Разрешения → Дополнительные разрешения** и разреши **«Выполнять команды в Termux»** (формулировка может отличаться).
2. В `~/.termux/termux.properties` должно быть:

```properties
allow-external-apps = true
```

3. Закрой и снова открой Termux. В приложении DERMUX RU выбери **Настройки → Связь Termux** для подсказок.

## Как работает домашний виджет

1. При первом запуске приложение пробует запросить закрепление виджета у лаунчера Android. Подтверди его системный запрос.
2. Если ничего не произошло: на главном экране зажми пустое место → **Виджеты → DERMUX — КОЛЕСО КОМАНД** → перетащи виджет.
3. Один тап по виджету открывает круговой selector. Выбери сектор, команду, введи цель при необходимости.
4. По центру колеса — назад к категориям; «Далее» листает следующие 8 команд.

## Безопасность и конфиденциальность

- DNS/WHOIS/RDAP/CT и web-метаданные запрашиваются у внешних публичных сервисов или выбранного сайта. Домен может попасть в логи этих сервисов.
- Запрос публичного IP показывает отдельное предупреждение.
- OSINT — только публичные данные. Используй его для собственных доменов или с разрешением.
- LAN discovery разрешает только частные IPv4-диапазоны от /24 до /32 и запрашивает согласие. Нет подбора паролей, эксплуатации уязвимостей или скрытого доступа к устройствам.
- Не включай `allow-external-apps=true`, если не устанавливаешь собственное DERMUX-приложение и не понимаешь последствий.

## Диагностика

- Меню открывается, команды не запускаются: проверь `allow-external-apps=true`, Android-разрешение DERMUX RU и наличие `~/.dermux/android/dispatch.sh`.
- Нет виджета в списке: проверь, что APK установлен; перезапусти лаунчер или перезагрузи телефон. Если авто-запрос не поддержан, добавь вручную через системный экран виджетов.
- Ошибка `RUN_COMMAND`: проверь, что Termux версии с поддержкой `RUN_COMMAND` и дополнение установлены из совместимого источника/подписи.
- Батарея/Wi‑Fi не отображаются: это использует Termux:API и зависит от разрешений Android; остальные инструменты работают отдельно.

## Структура

- `android/` — проект Android Studio (Java, без сторонних runtime-библиотек).
- `termux/install-termux.sh` — установщик Termux-части и диалог согласия для внешнего bridge.
- `termux/android/dispatch.sh` — bridge со строгим allowlist.
- `termux/DERMUX_ULTRA_by_osaoda/` — базовая библиотека, системная тема и существующие скрипты.
- `.github/workflows/build-debug-apk.yml` — CI-сборка debug APK.

## Выбор языка
В приложении нажми на строку под заголовком DERMUX (COMMAND WHEEL / КРУГОВОЙ ПУЛЬТ). Откроется выбор **Русский / English**. Выбор сохраняется между запусками. В текущей версии переведены основные экраны, категории, навигация и распространённые названия действий; часть подробных описаний ещё остаётся на русском.
