# Виджет DERMUX RU — краткая инструкция

**Это один настоящий Android AppWidget, а не список ярлыков Termux:Widget.** Его задача — быть компактной кнопкой на главном экране, одним касанием открывать собственный круговой селектор.

## Автодобавление

Android требует подтверждение пользователя перед закреплением виджета. При первом открытии DERMUX RU запросит закрепление, если лаунчер поддерживает эту функцию. Нажми «Добавить». В любой момент можно нажать «＋ ВИДЖЕТ» внутри приложения. Если функция отсутствует в твоём лаунчере, зажми пустую область главного экрана и найди `DERMUX — КОЛЕСО КОМАНД` в системном списке виджетов.

## Как выбирать команды

- Внешнее кольцо содержит 8 секторов-категорий.
- Тап по сектору открывает команды выбранной категории.
- Внутри категории используй «Далее» для следующей страницы.
- Тап по центральному кругу возвращает к категориям.
- Команды, которым нужен домен/IP/текст/путь, сначала показывают русское поле ввода.
- Для интернет-запросов библиотека Termux выводит текст подтверждения. Не подтверждай запрос, если цель тебе не принадлежит и у тебя нет разрешения на проверку.

## Почему виджет не показывает живые значения постоянно

Круговой selector — полноценный экран приложения. Сам домашний виджет — небольшой элемент RemoteViews, который открывает это меню. Такая архитектура значительно надёжнее, чем пытаться рисовать кастомный Canvas непосредственно внутри Android AppWidget; Android-виджеты используют ограниченный набор удалённых представлений.
