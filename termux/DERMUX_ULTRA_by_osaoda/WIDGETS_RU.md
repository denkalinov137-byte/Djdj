# DERMUX ULTRA — настройка виджетов

**Главный виджет не станет кастомной live-панелью.** Termux:Widget показывает список действий; кастомные PNG применяются к ярлыкам отдельных скриптов.

1. Установи Termux:Widget из источника, совместимого по подписи с Termux.
2. Запусти `widgetdoctor` в Termux.
3. Открой Termux:Widget → `REFRESH`.
4. Домашний экран → удержать пустое место → Виджеты → Termux:Widget → добавить список 2×2.
5. Нажимай папки категорий; для отдельного значка добавь `Termux shortcut` 1×1 и выбери скрипт.
6. Termux:Widget → `CREATE SHORTCUTS` публикует избранные dynamic shortcuts; лимит количества задаёт Android/лаунчер.

Если список пуст: проверь `~/.shortcuts`, разрешения и наличие самого приложения Termux:Widget. Затем открой Termux:Widget и нажми `REFRESH`. Приложения Termux и его дополнения должны быть из совместимых источников/подписей.

Официальная инструкция: https://github.com/termux/termux-widget#readme
